# Cuatro retos Flutter

Aplicación que reúne los cuatro ejercicios del documento:

1. **Recomendador de películas:** consulta películas populares por género con TMDB.
2. **Memes de gatos:** genera imágenes con texto usando Cataas.
3. **Clima (opcional):** consulta el clima actual por ciudad con WeatherAPI.
4. **Convertidor de criptomonedas:** consulta Bitcoin, Ethereum y Solana con CoinGecko y calcula la cantidad equivalente para un monto en USD.

## Cómo ejecutar

1. Abre la carpeta `cuatro_retos` en Visual Studio Code o Android Studio.
2. Ejecuta `flutter pub get`.
3. Ejecuta `flutter run`.

## Claves de API

- **TMDB:** crea una cuenta en The Movie Database y genera una API key. Pégala en la sección Películas.
- **WeatherAPI:** crea una cuenta en WeatherAPI y copia tu API key. Pégala en la sección Clima.
- **Cataas:** no requiere clave.
- **CoinGecko:** el endpoint público utilizado no requiere clave.

Las claves se ingresan desde la aplicación; no están guardadas en el código.
